Page: /crosswords?date=mm/dd/yyyy

Tech Stack: React + TypeScript, SCSS Modules (no Tailwind or similar), Dark Mode UI, Google OAuth (JWT).

Data Loading: 
- Fetch crosswords for date via getCrosswords API. Re-fetch crosswords when date changes.
- API Response Schema: Will be returned as an array of ClueCollection objects.

Layout
1. Selected Date and Calendar icon (Top, Side-by-Side)
  - In the format "Wednesday, May 13, 2026"
  - On each side of the date, arrows to go back or forward a day, except don't allow going past today.
  - The calendar icon opens the CrosswordCalendar component (separate component, overlays this component). 
    Includes FontAwesome icon and label "Calendar/Stats".
  - By default the selected date is today's date.
  
2. A list of crosswords for the selected date. For each crossword, there is a box with a generic thumbnail image on the left 
   and the following three lines to the right of it: 
    1. The publication full name (normal letters)
    2. The crossword title (bigger letters)
    3. "By: <Author> • <Clue Count> clues (<6 plus count> >= 6 letters)"
    4. A progress bar, with green representing Completed clues and gray otherwise. There are no labels for the bar, 
       just a rectangular bar. The progress bar does not show up if there is no logged in user. If there is a user but no
       progress for a clue, it should be considered incomplete.
- The thumbnail will be crossword_thumb.png.
- Clicking a crossword takes the user to the Crossword Solver page for that crossword. (separate component)
